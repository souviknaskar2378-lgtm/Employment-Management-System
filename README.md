# Employment Management System

A Python-based Employment Management System for managing employee records.

## Features

- Add Employee
- Display All Employees
- Search Employee
- Update Employee
- Delete Employee
- Salary Details
- Department-wise Employees
- CSV File Storage

## Technologies Used

- Python
- CSV File Handling

## How to Run

1. Download the project.
2. Install Python.
3. Open the project folder.
4. Run:

```bash
python employment_management_system.py
